Privacy Policy

Transparency about the data stored by NaughtyJar and how it's protected.

Last updated: August 28, 2026

Data stored

NaughtyJar may store locally: names or nicknames, optional photos, moments, values, notes, promises, cycles, preferences, and security activity. Sensitive fields are encrypted before being saved.

Collection and sharing

The current version does not send these records to the developer or to any server, does not sell them, and does not use advertising, analytics, or tracking. There is no NaughtyJar account and no developer server.

Photos

The photo is optionally chosen through the iOS picker. The app only stores the selected photo, encrypted on the device, and does not browse or send your photo library.

Premium widget and notifications

The widget is an optional Premium feature. It is technically implemented, but purchases are not active yet. When Premium access is available, it can hide identity and value. Notifications are local, optional, and use neutral text, with no names, values, or intimate details.

Purchases and security

Purchases are not active yet. If enabled, they will be processed by Apple. The app can be protected by biometrics and/or a passcode; the passcode is not stored in plain text. If recovery is started using device authentication, a new NaughtyJar code must be created before data is shown. The event, date, time, and available location are stored locally. When the app code is set up, the app explains why it needs location and asks for an explicit choice. If authorized, location is collected only during a recovery and never prevents access if unavailable. After the new code is saved, if notifications are authorized, a discreet alert is scheduled for the user-selected delay (two hours by default). Security activity also records a local lockout after three consecutive incorrect passcodes, with its date, time, and attempt count; normal unlocks are not recorded.

Manual backup

Premium backup is technically implemented, but purchases are not active yet. When access is available, users will be able to create a complete encrypted .njbackup file using a password that NaughtyJar does not store and cannot recover. The user chooses the destination in the iOS Files picker, including local storage, iCloud Drive, or another installed provider. The developer does not receive the file. The backup includes security activity, including available locations from access recoveries, and excludes the app passcode, biometric settings, notification permissions, and Premium entitlement. Restoring will replace current data only after confirmation.

Deleting data

In NaughtyJar's Settings you can permanently delete all local data. Uninstalling the app also removes local data, without affecting backups managed by iOS.
