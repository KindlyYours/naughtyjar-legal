Privacy Policy

Transparency about the data stored by NaughtyJar and how it's protected.

Last updated: August 28, 2026

Data stored

NaughtyJar may store locally: names or nicknames, optional photos, moments, values, notes, cycles, preferences, and security activity. Sensitive fields are encrypted before being saved.

Collection and sharing

The current version does not send these records to the developer or to any server, does not sell them, and does not use advertising, analytics, or tracking. There is no NaughtyJar account and no developer server.

Photos

The photo is optionally chosen through the iOS picker. The app only stores the selected photo, encrypted on the device, and does not browse or send your photo library.

Widget and notifications

The widget is optional and can hide identity and value. Notifications are local, optional, and use neutral text, with no names, values, or intimate details.

Security

The app can be protected by biometrics and/or a passcode; the passcode is not stored in plain text. If recovery is started using device authentication, a new NaughtyJar code must be created before data is shown. The event, date, time, and available location are stored locally.

Manual backup

Manual backup is free. It creates an encrypted .njbackup file with a password that NaughtyJar does not store and cannot recover. The user chooses the destination in the iOS Files picker and the developer does not receive the file. Restoring replaces current data only after confirmation.

Deleting data

In NaughtyJar's Settings you can permanently delete all local data. Uninstalling the app also removes local data, without affecting backups managed by iOS.

Contact

For privacy questions, reach out via email kindly.yours@icloud.com.
